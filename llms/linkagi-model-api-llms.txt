# LinkAGI

LinkAGI 是面向国内开发者的 AI API 中转站与模型 API 接入服务。主站提供注册、人民币充值、令牌管理、实时模型价格和调用日志；文档站提供 Codex、Claude Code、Gemini CLI 与 OpenAI-compatible 客户端的接入和排错教程。

## 核心入口

- 控制台: https://api.linktoagi.com/
- 注册: https://api.linktoagi.com/register
- 实时模型与价格: https://api.linktoagi.com/pricing
- 简明使用教程: https://docs.linktoagi.com/
- API 中转站选型指南: https://docs.linktoagi.com/api-relay.html
- GPT API 中转站介绍: https://docs.linktoagi.com/gpt-api.html

## API 发现与机器可读资产

- API 发现页: https://docs.linktoagi.com/api-discovery.html
- OpenAPI 3.1: https://docs.linktoagi.com/openapi/linkagi.openapi.json
- APIs.json: https://docs.linktoagi.com/apis.json
- Postman 公开集合: https://www.postman.com/lhs-1-s-team/linkagi-api/collection/8nl8r40/linkagi-api
- GitHub 入门仓库: https://github.com/16871233/linkagi-api-starter

证据边界（2026-08-04）：公开成功样本仅验证 Chat Completions 的 `claude-opus-4-6` 与 Responses 的 `gpt-5.6-sol` 各一次 HTTP 200。它们不证明长期可用、流式输出、工具调用、原生 Anthropic Messages、Gemini、客户端专用兼容性或已鉴权模型列表。无 Key 返回 401 只证明路由到达鉴权层。

## 按工具接入

- Codex 中转站: https://docs.linktoagi.com/codex-api.html
  - Base URL: https://api.linktoagi.com/v1
  - 协议: Responses
- Claude Code 中转站: https://docs.linktoagi.com/claude-code-api.html
  - ANTHROPIC_BASE_URL: https://api.linktoagi.com
  - 路由: /v1/messages
- Gemini CLI 中转站: https://docs.linktoagi.com/gemini-cli-api.html
  - GOOGLE_GEMINI_BASE_URL: https://api.linktoagi.com
  - 路由: /v1beta/models/...
